# 🌱 Instituto Educa — Website

Projeto de repaginação do site do Instituto Educa, uma organização da sociedade civil voltada ao fortalecimento de Povos e Comunidades Tradicionais por meio da educação, gestão social e promoção de direitos humanos.

---

## 🚀 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de modernizar a presença digital do Instituto Educa, trazendo:

- Melhor experiência do usuário (UX)
- Layout responsivo (mobile-first)
- Estrutura visual mais clara e institucional
- Organização de conteúdo (projetos, impacto, documentos)

A proposta foi recriar o front-end com maior controle de layout e performance, mantendo compatibilidade com futura integração ao WordPress.
